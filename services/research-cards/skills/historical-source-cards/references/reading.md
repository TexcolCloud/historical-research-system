# 逐段阅读分支

适用：宿主要求 `ReadingRecord`。遵循本次实际 Schema；下列字段对应当前制卡模块。

## 阅读与回查

1. 从 `assignment` 确认文献目标，用 `research_state` 与 `previous_reading` 接续进度。完整读取本批 `source_units`，严格按输入顺序各生成一条 `readings`。关注点帮助选择解释重点，不允许跳过其余单元。
2. `context_units` 和工具取得的邻段是理解背景，不增加本批覆盖条数。遇到跨栏、跨页半句，沿宿主提供的来源与续文关系补读；不因两段相邻就认定属于同篇或同一段。
3. 检查 `context_deferred_unit_ids`：针对确实影响本批理解的未载上下文调用 `read_source_units`。同次需要的已知 ID 可合并请求，遵守工具数量和返回长度限制；长内容按 `next_read` 续读。
4. 对脚注或表注，先确认显式关系及上下文。重复的“①”不是唯一身份，通栏脚注的位置不能确定它属于左栏还是右栏。无法确认时保留条件缺口，不转写为正文事实。
5. 存在未解决的实质问题才形成研究问题。优先使用已有原文回答；版式、识字和原件不清的问题交接给原图核查，不用无关外部检索代替。

## 紧凑记录

| 字段 | 写什么 |
| --- | --- |
| `unit_id` | 原样使用本批真实单元 ID |
| `main_records` | 本单元新增且有研究意义的具体记载；避免重复全篇背景 |
| `attribution` | 谁在陈述、处于哪一来源层次；依据不足时写明未知 |
| `dates_quantities_actors` | 关键时间、数量与单位、主体及统计范围 |
| `negations_and_limits` | 否定、条件、例外、不能推出的结论 |
| `note_table_dependencies` | 影响解释的注释、表头、行列与续文，附已知关联 ID；归属未知要明确 |
| `candidate_quotes` | 本单元值得保留的逐字连续原文；不凑数量、不跨单元拼接 |
| `uncertainties` | 尚未解决的具体歧义及其影响；已由原文解决的不再列入 |

字段承担不同职责，无内容的列表用空数组；识别到的关键条件不可为了压缩而省略。短标题、书目和接续词按实际功能记录，不从中扩写不存在的历史判断。

顶层 `themes`、`structure` 写本批新增线索；`boundary_observations` 只写实际篇界证据，不从阅读进度猜全文完整。每个 `questions` 条目给出问题、已有证据、缺少什么、真实 `source_unit_ids` 和是否主材料内可查。

## 提交前检查

- `readings` 与本批 ID、顺序一一对应，无遗漏、重复或额外上下文单元。
- 每条候选引文都是对应原文的连续子串；释读与引用分开。
- 关键脚注条件和冲突已在记录中体现，或明确列为未解。
- 输出止于阅读记录；最终综合、独立核查与采用交给各自阶段。
