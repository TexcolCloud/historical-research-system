## 原图观察也会出错

本轮默认工作区的郭村报告两页由后台子代理完成 OCR、独立审核和组织并发布。独立终验最初将第五条中的一字判作“政”，认为候选“攻”有误；随后通过高层 MCP 开启复核版本，运行子代理按新增的原图优先协议再次检查，仍读作“攻”。

再次隔离原 PDF 的原始字形，未接触候选的核查者无法唯一确认其左部的“工／正”关键笔画。先前“政”为确定读法的表述过早，已保留初次报告和追加观察，最终定为原件读法分歧，**没有按上下文或模型多数强改候选**，也不将待审称作修复成功。

实际独立审计子代理调用 `request_human_review`，提交当前原图/文本哈希、真实细节元数据与未解决观察。第 3 版进入 `pending / waiting_human`，物理第 2 页仍 approved，前两版发布及其回执保留。没有填写真实史料的人工表单；现有候选、相反观察与旧审计都保持原样。新的机器重试不能取代人工确认，真正的最后一页人工确认后仍会自动排队接续。

这更新了本轮对同页字形的内容结论。[此前验收](UNIFIED-VALIDATION.md) 保留历史运行及观察，不作为当前该字已解决的证明；[更早宁夏史歧义](ACCEPTANCE.md) 也未被关闭或清理。

## 浏览器实测

所有网页操作使用 Codex 应用内浏览器。合成图片明确标注测试用途，人工表单均署名“自动化测试（合成样本）”，不计作真实史料内容验收。

- 无效导入保留网址、文件路径和标题，在原页显示错误；没有增加空文档。
- 后台新增文档后列表自动更新，导入输入不变；新增待审页插到队首时，正在编辑的原页不切换、草稿不被覆盖。
- 未勾选整页确认时，批准被拒绝，正文、审核人及依据保留。
- 模拟临时断网，保存失败保留完整输入；恢复网络后自动重连，并可保存同一份草稿。网络模拟已恢复。
- 保存待审草稿后仍停留同一文档与物理页；另一窗口更新该页后，当前编辑保留，旧版本提交被禁用。
- 合成页通过新版网页确认后，后台 MCP 原生子代理自动组织、发布和检索；真实争议页只展示原图与待审表单，没有代填决定。
- 默认工作台重启后保留真实文档的 published / succeeded 与 pending / waiting_human；正文主题检索命中物理第 2 页，争议报告的旧发布显示新版本复核提示。

实测修复了队列重排误判当前页已变、保存草稿跳回队首、嵌入浏览器不透明 Origin 的同源表单问题。访问令牌、准确 Host 和浏览器控制的同源 Fetch Metadata 仍被校验；脚本及同步请求仅允许本站来源。
